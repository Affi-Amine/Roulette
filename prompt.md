## 📋 PROJECT CONTEXT

### What This App Does:
1. **Customer Flow:**
   - Customer buys pizza → Cash register prints receipt with QR code
   - Customer scans QR code → Verifies ticket validity
   - Customer spins prize wheel (multiple times based on pizzas purchased)
   - Customer enters name/phone → Prizes saved to database
   - Customer shows staff → Staff validates prizes in dashboard

2. **Staff Flow:**
   - Search customer by name or phone number
   - View their won prizes
   - Mark prizes as "validated" when redeemed

3. **Admin Flow:**
   - View all users, prizes, spins
   - Manage prize catalog (add, edit, activate/deactivate)
   - Configure prize probabilities for simple vs premium spins
   - View analytics

### Key Business Rules:
- **1 classic pizza = 1 simple spin**
- **1 premium pizza = 1 premium spin**
- **Each ticket can only be scanned ONCE** (anti-rescan)
- **QR codes are 100% offline** (generated by cash register, no API call)
- **HMAC signature** prevents ticket fraud
- Prizes have different probabilities for simple vs premium spins

## 🔐 CRITICAL: QR CODE VERIFICATION (HMAC)

### How QR Codes Work (Offline System):

The **cash register** generates QR codes with this JSON structure:
```json
{
  "ticket_id": "T20250111-000456",
  "nb_pizzas_classiques": 2,
  "nb_pizzas_premium": 1,
  "sig": "c87f2d8a3aa4b7c6d5e8f9a0b1c2d3e4..."
}
```

### HMAC Signature Verification:

**The signature PREVENTS FRAUD.** Here's how it works:

```typescript
// 1. Cash register creates signature (you don't build this):
const message = `${ticket_id}|${nb_pizzas_classiques}|${nb_pizzas_premium}`;
const signature = HMAC_SHA256(SECRET_KEY, message);

// 2. YOUR API must verify it:
import { createHmac } from 'crypto';

function verifyTicket(ticket_id: string, nb_pizzas_classiques: number, 
                      nb_pizzas_premium: number, sig: string): boolean {
  const SECRET_KEY = process.env.HMAC_SECRET!; // Store in .env
  
  // Reconstruct message EXACTLY as cash register did
  const message = `${ticket_id}|${nb_pizzas_classiques}|${nb_pizzas_premium}`;
  
  // Calculate expected signature
  const expectedSig = createHmac('sha256', SECRET_KEY)
    .update(message)
    .digest('hex');
  
  // Compare (use timing-safe comparison in production)
  return sig === expectedSig;
}
```

## 🎰 PRIZE SELECTION ALGORITHM (Weighted Random)

Prizes have **probability weights** for simple vs premium spins.

### Implementation:

```typescript
// Option 1: Database Function (Recommended)
// Create this PostgreSQL function:
CREATE OR REPLACE FUNCTION select_random_prize(spin_type TEXT)
RETURNS UUID AS $$
DECLARE
  total_weight INTEGER;
  random_value INTEGER;
  selected_prize_id UUID;
  cumulative_weight INTEGER := 0;
BEGIN
  -- Get total weight for this spin type
  SELECT SUM(
    CASE 
      WHEN spin_type = 'simple' THEN weight_simple
      WHEN spin_type = 'premium' THEN weight_premium
    END
  ) INTO total_weight
  FROM prizes
  WHERE active = true;
  
  -- Generate random number [0, total_weight)
  random_value := floor(random() * total_weight);
  
  -- Find prize using cumulative weight
  FOR prize_record IN 
    SELECT id, 
           CASE 
             WHEN spin_type = 'simple' THEN weight_simple
             WHEN spin_type = 'premium' THEN weight_premium
           END as weight
    FROM prizes
    WHERE active = true
    ORDER BY id
  LOOP
    cumulative_weight := cumulative_weight + prize_record.weight;
    IF cumulative_weight > random_value THEN
      selected_prize_id := prize_record.id;
      EXIT;
    END IF;
  END LOOP;
  
  RETURN selected_prize_id;
END;
$$ LANGUAGE plpgsql;

// Option 2: TypeScript Implementation (if you prefer):
async function selectRandomPrize(spinType: 'simple' | 'premium'): Promise<string> {
  const { data: prizes } = await supabase
    .from('prizes')
    .select('id, weight_simple, weight_premium')
    .eq('active', true);
  
  const weightKey = spinType === 'simple' ? 'weight_simple' : 'weight_premium';
  const totalWeight = prizes.reduce((sum, p) => sum + p[weightKey], 0);
  
  let random = Math.random() * totalWeight;
  
  for (const prize of prizes) {
    random -= prize[weightKey];
    if (random <= 0) {
      return prize.id;
    }
  }
  
  return prizes[0].id; // Fallback
}
```

### 1. POST /api/verify-ticket

**Purpose:** Validate QR code and register ticket in database

```typescript
// app/api/verify-ticket/route.ts
import { NextRequest, NextResponse } from 'next/server';
import { createHmac } from 'crypto';
import { createClient } from '@supabase/supabase-js';

export async function POST(req: NextRequest) {
  const { ticket_id, nb_pizzas_classiques, nb_pizzas_premium, sig } = await req.json();
  
  // 1. Verify HMAC signature
  const message = `${ticket_id}|${nb_pizzas_classiques}|${nb_pizzas_premium}`;
  const expectedSig = createHmac('sha256', process.env.HMAC_SECRET!)
    .update(message)
    .digest('hex');
  
  if (sig !== expectedSig) {
    return NextResponse.json({ error: 'Invalid signature' }, { status: 400 });
  }
  
  // 2. Check if ticket already used (anti-rescan)
  const supabase = createClient(process.env.NEXT_PUBLIC_SUPABASE_URL!, 
                                 process.env.SUPABASE_SERVICE_KEY!);
  
  const { data: existingTicket } = await supabase
    .from('tickets')
    .select('ticket_id')
    .eq('ticket_id', ticket_id)
    .single();
  
  if (existingTicket) {
    return NextResponse.json({ error: 'Ticket already used' }, { status: 409 });
  }
  
  // 3. Calculate spins
  const spins_simple = nb_pizzas_classiques;
  const spins_premium = nb_pizzas_premium;
  
  if (spins_simple === 0 && spins_premium === 0) {
    return NextResponse.json({ error: 'No spins available' }, { status: 400 });
  }
  
  // 4. Insert ticket into database
  const { error: insertError } = await supabase
    .from('tickets')
    .insert({
      ticket_id,
      nb_pizzas_classiques,
      nb_pizzas_premium,
      spins_simple_remaining: spins_simple,
      spins_premium_remaining: spins_premium,
      is_used: true
    });
  
  if (insertError) {
    return NextResponse.json({ error: 'Database error' }, { status: 500 });
  }
  
  // 5. Return success
  return NextResponse.json({
    valid: true,
    ticket_id,
    spins: {
      simple: spins_simple,
      premium: spins_premium
    }
  });
}
```

### 2. POST /api/spin

**Purpose:** Execute a spin, decrement spin count, return prize

```typescript
// app/api/spin/route.ts
export async function POST(req: NextRequest) {
  const { ticket_id, spin_type } = await req.json(); // 'simple' or 'premium'
  
  const supabase = createClient(process.env.NEXT_PUBLIC_SUPABASE_URL!, 
                                 process.env.SUPABASE_SERVICE_KEY!);
  
  // 1. Get ticket and check remaining spins
  const { data: ticket, error } = await supabase
    .from('tickets')
    .select('*')
    .eq('ticket_id', ticket_id)
    .single();
  
  if (error || !ticket) {
    return NextResponse.json({ error: 'Ticket not found' }, { status: 404 });
  }
  
  const remainingKey = spin_type === 'simple' 
    ? 'spins_simple_remaining' 
    : 'spins_premium_remaining';
  
  if (ticket[remainingKey] <= 0) {
    return NextResponse.json({ error: 'No spins remaining' }, { status: 400 });
  }
  
  // 2. Select random prize (using database function)
  const { data: prizeId } = await supabase
    .rpc('select_random_prize', { spin_type });
  
  // 3. Get prize details
  const { data: prize } = await supabase
    .from('prizes')
    .select('*')
    .eq('id', prizeId)
    .single();
  
  // 4. Record spin in database
  const { data: spin } = await supabase
    .from('spins')
    .insert({
      ticket_id,
      prize_id: prizeId,
      spin_type
    })
    .select()
    .single();
  
  // 5. Decrement spin count
  await supabase
    .from('tickets')
    .update({ [remainingKey]: ticket[remainingKey] - 1 })
    .eq('ticket_id', ticket_id);
  
  // 6. Return prize
  return NextResponse.json({
    spin_id: spin.id,
    prize_id: prize.id,
    prize_name: prize.name,
    prize_emoji: prize.emoji,
    prize_color: prize.color
  });
}
```

```typescript
// app/api/claim-prizes/route.ts
export async function POST(req: NextRequest) {
  const { ticket_id, name, phone, spin_ids } = await req.json();
  
  const supabase = createClient(process.env.NEXT_PUBLIC_SUPABASE_URL!, 
                                 process.env.SUPABASE_SERVICE_KEY!);
  
  // 1. Create or get user
  let { data: user } = await supabase
    .from('users')
    .select('*')
    .eq('phone', phone)
    .single();
  
  if (!user) {
    const { data: newUser } = await supabase
      .from('users')
      .insert({ name, phone })
      .select()
      .single();
    user = newUser;
  }
  
  // 2. Link user to ticket
  await supabase
    .from('tickets')
    .update({ user_id: user.id })
    .eq('ticket_id', ticket_id);
  
  // 3. Create user_prizes for each spin
  const { data: spins } = await supabase
    .from('spins')
    .select('id, prize_id')
    .in('id', spin_ids);
  
  const userPrizes = spins.map(spin => ({
    user_id: user.id,
    spin_id: spin.id,
    prize_id: spin.prize_id,
    status: 'obtained'
  }));
  
  await supabase
    .from('user_prizes')
    .insert(userPrizes);
  
  // 4. Return success
  return NextResponse.json({
    success: true,
    user_id: user.id
  });
}
```

### Supabase Auth Setup:

```typescript
// 1. Create admin user in Supabase dashboard:

// 2. Middleware to protect admin routes:
// middleware.ts
import { createMiddlewareClient } from '@supabase/auth-helpers-nextjs';
import { NextResponse } from 'next/server';
import type { NextRequest } from 'next/server';

export async function middleware(req: NextRequest) {
  const res = NextResponse.next();
  const supabase = createMiddlewareClient({ req, res });
  
  const { data: { session } } = await supabase.auth.getSession();
  
  // Protect /admin routes
  if (req.nextUrl.pathname.startsWith('/admin')) {
    if (!session) {
      return NextResponse.redirect(new URL('/admin/login', req.url));
    }
  }
  
  // Protect /api/admin routes
  if (req.nextUrl.pathname.startsWith('/api/admin')) {
    if (!session) {
      return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
    }
  }
  
  return res;
}

export const config = {
  matcher: ['/admin/:path*', '/api/admin/:path*']
};
```

## 🚨 CRITICAL SECURITY REMINDERS

1. **NEVER expose HMAC_SECRET client-side**
   - Must be in .env.local (gitignored)
   - Only used in API routes (server-side)

2. **Use SUPABASE_SERVICE_KEY only server-side**
   - For API routes that bypass RLS
   - Never expose to client

3. **Validate ALL inputs**
   - Sanitize ticket_id, name, phone
   - Prevent SQL injection (use Supabase parameterized queries)

4. **Rate limiting** (optional but recommended)
   - Limit /api/verify-ticket to 10 requests/minute per IP
   - Prevent abuse

5. **Row Level Security (RLS)**
   - Enable RLS on all tables
   - Service role key bypasses RLS (which is what you need)
